## Tietoturvavahti

**CVE-2026-54316: Claude Code käytti HuggingFace-lataustilastoja API-avaimen eksfiltraatiokanavana – korjattu 2.1.163 (Novee Security, julkistettu Black Hat 5.8.; CVE-tiedot julkaistu tällä viikolla)**

*Seuranta: Black Hat 5.8. "Trusted Enough to Run" -esittely (harness-luottamuksen siirtymisvirhe) käsitelty 8/5-raportissa. Uusi: tuon esityksen rinnalla paljastettu erillinen eksfiltraatiomekanismi sai nyt oman CVE-numeron ja täyden teknisen raportin.*

Haavoittuvuuden mekanismi on erilainen kuin 8/5-raportissa käsitelty harness-design-gap: Claude Code sisälsi `huggingface.co`-domainin ennakkohyväksyttyjen WebFetch-kohteiden listalla. Hyökkääjä voi rakentaa piilotun eksfiltraatiokanavan, jossa data siirretään ulos API-avaimen merkkiä kerrallaan käyttäen HF:n julkista lataustilastolaskuria – ei vaadi ennakolta autentikoitua HF-tunnusta. Kaikki versiot 0.2.54–2.1.162 ovat haavoittuvaisia. **Korjaus: päivitä Claude Code 2.1.163+.** Anthropic luokitteli vakavuuden "Moderate" (sisäinen arvio CVSS v4 6.0); NVD antoi CVSS v3.1 9.1. Rinnakkainen löytö samasta esityksestä: Gemini CLI CVE-2026-12537 (CVSS 10.0) – OS command injection containerilauncher-komponentin kautta craftattu `.gemini/.env`-tiedosto; **korjaus: päivitä Gemini CLI 0.39.1+ ja run-gemini-cli 0.1.22+.** [The Hacker News: Claude Code and Gemini CLI Flaws Let a GitHub Issue Reach CI Workflow Secrets](https://thehackernews.com/2026/08/claude-code-and-gemini-cli-flaws-let.html) | [GitLab Advisory: CVE-2026-54316](https://advisories.gitlab.com/npm/@anthropic-ai/claude-code/CVE-2026-54316/) | [cvemon: CVE-2026-54316](https://cvemon.intruder.io/cves/CVE-2026-54316) | [eSecurity Planet: Black Hat 2026 Critical Flaws](https://www.esecurityplanet.com/threats/black-hat-2026-critical-flaws-found-in-anthropic-google-and-openai-coding-agents/) | [Novee Security: Critical Flaws in AI Coding Agents](https://novee.security/blog/critical-flaws-in-anthropic-google-and-openais-coding-agents/)

*Miksi tärkeä / mitä kokeilla:* Kolme välitöntä toimenpidettä: (1) **Päivitä Claude Code 2.1.163+ heti** – kaikki aiemmat versiot haavoittuvaisia, myös 2.1.32 joka sisälsi GhostApproval-mitigaation; (2) **Päivitä Gemini CLI 0.39.1+** – CVSS 10.0 tarkoittaa täyttä hallintaa hostin komentorivillä; (3) **Tarkista CI/CD-konfiguraatiosi**: kolmannen osapuolen WebFetch-domainit jotka ovat ennakkohyväksyttyjä muodostavat vastaavan riskin vaikkei niitä tässä CVE:ssä mainitakaan. Varmista ettei `ANTHROPIC_API_KEY` tai vastaava ole CI-ympäristömuuttujana ilman tarpeellista rajausta.

**Claude Code Auto Mode tulee oletukseksi Pro/Max/Team-käyttäjille 14.8.2026 (Simon Willison 8.8.; ei käsitelty aiemmissa raporteissa)**

Anthropic vaihtaa Claude Coden oletuslupatilan Pro-, Max- ja Team-tileille Auto Modeen 14.8.2026. Auto Mode: jokainen riskialtis tool call menee ennakoivalle luokittimelle, joka hyväksyy tai hylkää ilman käyttäjän manuaalista napinpainallusta. Enterprise, API, Bedrock, Google Cloud, Azure ja AWS pysyvät opt-in -tilassa. Järjestelmänvalvojat voivat kiinnittää eri oletuksen tai poistaa Auto Moden hallinnoiduista asetuksista. ## Saatavuus- ja sääntelyriskit

**Anthropic vesileimaa kaiken Claude-tuottaman tekstin maailmanlaajuisesti – EU AI Act Art. 50 ajaa globaalin muutoksen (julkaistu 11.8.2026)**

Anthropic ilmoitti 11.8., että kaikki uudet Claude-mallit elokuun 2. jälkeen upottavat "imperceptible" koneluettavan vesileiman suoraan tuottamaansa tekstiin. Merkki ei muuta tekstin merkitystä, laatua tai luettavuutta mutta "kulkee copy-pasten mukana ja voi säilyä läpi joitakin muokkauksia". Kattavuus: kaikki Clauden tuottama teksti verkkosivustolla, Claude Codessa, Claude Coworkissa, Claude Tagissa ja kaikissa API-integraatioissa (myös AWS, Google Cloud, Microsoft Foundry). EU AI Act artikla 50 (transparency obligations) tuli voimaan 2.8.2026 – mutta Anthropic päätti soveltaa muutosta globaalisti eikä pelkästään EU:ssa. Tulossa: kolmansille osapuolille suunnattu detektiorajapinta, jolla voi tunnistaa Claude-tuottaman tekstin. Vanhemmat mallit saavat vesileiman retrofitinä myöhemmin. Anthropic korostaa: merkki todistaa Clauden *käsitelleen* tekstiä, ei sitä kuka on tekstin *tekijä*. *Miksi tärkeä / mitä kokeilla:* Neljä käytännön vaikutusta: (1) **Oikeudellinen ja compliance-näkökulma**: EU AI Act seuraamukset voivat olla jopa 15 M€ tai 3 % liikevaihdosta – globaali implementointi tarkoittaa ettei erillisiä EU-konfiguraatioita tarvita; (2) **Tuotenimihankkeet**: jos rakennat Claude-pohjaisen tuotteen joka generoi tekstisisältöä, käyttäjäsi tekstiin uppoaa vesileima – sisäistä ja asiakkaan päätä kohden; (3) **Detektio tulee kolmansille**: kun API on valmis, kilpailijat, toimittajat ja työnantajat voivat tarkistaa onko teksti Claude-tuottamaa; (4) **Forensiikka-aste**: "may persist through some editing" on varoitus – kuinka paljon muokkaus poistaa leiman on toistaiseksi dokumentoimatta; testaa ennen kuin luotat siihen.
