## Toimintatavat ja arkkitehtuuripatternit

**Agentin lataaman konfiguraation lukitseminen ja hyväksyntä diffinä CI:ssä** (Lockward-repon dokumentaatio, Show HN 26.11.) `[Kokeile]` - Skillit, MCP-palvelimet, hookit ja sääntötiedostot käsitellään kuin riippuvuudet:
- Niiden tila (tiedostojen tiivisteet, MCP-palvelinten versiot ja komennot, hookien komennot) tallennetaan lukkotiedostoon, joka commitoidaan repoon.
- PR-tarkistus epäonnistuu, jos jokin muuttuu ilman hyväksyntää.
- Muutos hyväksytään yksi kerrallaan diffin luettuaan, ja hyväksyjä kirjautuu ylös.

Sama malli kattaa myös "rug pull" -tapaukset, joissa luotettu paketti muuttuu myöhemmin haitalliseksi. Kertaskannaus ei sellaista huomaa, koska se katsoo vain hetken tilaa. [README](https://github.com/Breaktroughf1/lockward)
*Miksi tärkeä / mitä kokeilla:* Valitkaa yksi repo, jossa on yhteiset `.claude/skills`-, `.mcp.json`- ja hook-asetukset. Ajakaa siinä `lockward init && lockward lock`, commitoikaa `lockward.lock` ja lisätkää `lockward verify --frozen` PR-tarkistukseksi. Jos käytätte Azure Pipelinesia, ajakaa CLI suoraan, koska valmis action on vain GitHub Actionsille.

## Repot ja yhteisön tekniikat

**Lockward** (Show HN 26.11.; v0.2.1–0.2.3 loppuviikolla) `[Kokeile]` - Lockward on Go-kielinen CLI, joka toimii ilman verkkoyhteyttä ja ilman LLM:ää. Se tunnistaa Claude Coden, Cursorin, Codexin, Gemini CLI:n, Windsurfin ja GitHub Copilotin lataamat skillit, MCP-palvelimet, hookit ja sääntötiedostot ja lukitsee ne `lockward.lock`-tiedostoon. Muut ominaisuudet:
- Valmiit policy-säännöt, esim. LW001 (MCP-palvelinta ei ole kiinnitetty), LW003 (hook tekee verkkokutsuja) ja LW004 (skill käskee hakemaan tai ajamaan jotain ulkoisesta URL:stä).
- `scan-repo` tarkistaa vieraan repon ennen kuin sen avaa agentissa.
- Tulosteena SARIF-raportti code scanningiin ja CycloneDX 1.6 -muotoinen AI-BOM.
- Asennus Homebrew'lla, `go install`illa tai PyPI:stä. GitHub Marketplacessa on Sigstore-varmennettu "Lockward Verify" -action.

Projekti on uusi ja yhden tekijän ylläpitämä, joten se kannattaa ensin kokeilla rajatusti. [GitHub](https://github.com/Breaktroughf1/lockward) · [Show HN](https://news.ycombinator.com/item?id=50656050)
*Miksi tärkeä / mitä kokeilla:* Ajakaa `lockward scan-repo <polku>` asiakkaan tai avoimen lähdekoodin repolle ennen kuin avaatte sen Claude Codessa. Ajakaa myös `lockward bom` omalle kehittäjäkoneelle, niin näette, mitä skillejä ja MCP-palvelimia agentit oikeasti lataavat.

Muuta: gh-trends-koosteessa (26.11.) mainittiin OpenChatCut (paikallinen AI-videoeditori, jossa Agent Skills- ja MCP-tuki) ja Go-kielinen AI SDK ilman ulkoisia riippuvuuksia. Kumpikaan ei koske tiimin stackia suoraan.
