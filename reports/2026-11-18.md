# AI-aamuraportti - 2026-11-18

## Päivän tärkeimmät

- Microsoft Agent Frameworkin Python-paketin `agent-framework` versiot 1.26.1 ja 1.26.2 kaapattiin PyPI:ssä 17.11. Ne varastavat Azure-, Azure DevOps- ja GitHub Actions -tunnisteita heti Pythonin käynnistyessä. Jos jokin kone tai CI-ajo asensi ne noin klo 20.35–21.30 UTC välillä, kierrättäkää salaisuudet.

Esimerkiksi `claude mcp add/remove` project-scopella poisti muita avaimia `.mcp.json`-tiedostosta, ja Remote Controlin worktree-tila saattoi poistaa `.env`-tiedostoja. Uusi `claude mcp add-json <nimi> -` lukee palvelimen määrityksen stdinistä, joten tunnisteet eivät jää komentoriville.
- Microsoftin MAI Code 2 ja MAI Code 2 Flash tulivat Copilotiin. Microsoftin omien lukujen mukaan MAI Code 2 yltää noin 98 %:iin GPT-6.1 Solin tuloksista noin 40 %:lla sen hinnasta.

## Pluginit, skillit ja MCP

**Claude Code 2.1.327: MCP- ja plugin-korjaukset** (julkaistu 17.11.) `[Kokeile]` - Muutokset:
- `claude mcp add` ja `claude mcp remove` project-scopella poistivat aiemmin `.mcp.json`-tiedostosta muut ylätason avaimet, kuten `$schema` tai toisen työkalun `servers`-osion. Tämä on korjattu.
- Uusi `claude mcp add-json <nimi> -` lukee palvelimen JSON-määrityksen stdinistä, jolloin tokenit eivät päädy shell-historiaan.
- Etä-MCP-palvelimet (https, hostnamella) yritetään nyt yhdistää uudelleen taustalla noin vuorokauden ajan pidemmän katkon, esimerkiksi VPN-katkon, jälkeen.
- Pluginin agentti ei enää katoa, kun sessio jatketaan `--resume`-valitsimesta.
- Klikkaus ja Enter `/plugin`-näkymässä ei enää asenna tai poista pluginia vahingossa.

[CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Jos sama `.mcp.json` on jaettu VS Code- tai Copilot-määritysten kanssa, tarkistakaa `git diff`:llä, ettei aiempi `claude mcp add` ole poistanut niiden osioita. Lisätkää jatkossa tokenia vaativat palvelimet muodossa `echo '{...}' | claude mcp add-json ado -`.

## Tietoturvavahti

**Microsoft `agent-framework` (PyPI) kaapattu: versiot 1.26.1 ja 1.26.2** (julkaistu 17.11.) `[Kokeile]` - Microsoft Agent Frameworkin virallisesta Python-paketista julkaistiin 17.11. kaksi haitallista versiota 33 minuutin välein (noin klo 20.35 ja 21.08 UTC). Ne poistettiin PyPI:stä noin klo 21.30 UTC. Haittakoodi ajetaan `.pth`-startup-tiedostosta, joten se suoritetaan jokaisella Pythonin käynnistyksellä, vaikka pakettia ei koskaan importattaisi. Se kerää Azure-, Azure DevOps- ja GitHub Actions -tunnisteet ja lähettää ne hyökkääjän webhookiin. Viimeinen puhdas versio on 1.26.0. .NET-paketeista (NuGet) ei löytynyt raportteja. [OX Security](https://www.ox.security/blog/breaking-hijacked-releases-of-microsofts-official-agent-framework-steals-azure-and-ci-credentials/) · [Wiz](https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi) · [Aikido](https://www.aikido.dev/blog/two-malicious-agent-framework-releases-hit-pypi-in-33-minutes)
*Miksi tärkeä / mitä kokeilla:* Ajakaa `pip show agent-framework` kehittäjäkoneilla ja CI-agenteilla ja tarkistakaa lukitustiedostot (`grep -r "agent-framework" requirements*.txt poetry.lock uv.lock`). Jos 1.26.1 tai 1.26.2 on asentunut, poistakaa se, kiinnittäkää `agent-framework==1.26.0` ja kierrättäkää Azure-palveluprinsipaalit, ADO-PAT:t ja GitHub-tokenit.

Muuta: Copilot code review tunnistaa nyt salaisuuksia PR:istä (public preview, ks. Kehitystyökalut). Claude Code 2.1.327 korjasi useita tiedostoja poistavia virheitä: Remote Controlin worktree-tila saattoi poistaa git-ignoroidut tiedostot kuten `.env`, ja `--use-anthropic-git-proxy` saattoi poistaa `GIT_CONFIG_GLOBAL`-hakemiston. Uusia agentteja, MCP:tä tai kehitystyökaluja koskevia CVE:itä ei löytynyt ikkunasta, ja CVE-2026-103572 on käsitelty aiemmin.

## Syväluentaehdokkaat

- **Python-riippuvuuksien kiinnitys agenttiprojekteissa `agent-framework`-kaappauksen jälkeen:** Hyökkäys kohdistui juuri Azure- ja Azure DevOps -tunnisteisiin, ja `.pth`-tekniikka ohittaa import-pohjaiset tarkistukset. Käykää läpi, missä agentti- ja CI-ympäristöissä on löysiä versiorajauksia (`>=`), ottakaa käyttöön hash-lukitus (`uv lock` / `pip --require-hashes`) ja harkitkaa julkaisuviivettä, esim. uv:n `exclude-newer`, ettei juuri julkaistu versio asennu automaattisesti.
- **Copilot code review Azure Reposissa vs. Claude Code -katselmointi:** GA ja Adaptive effort tekevät Copilotista realistisen vaihtoehdon ADO-pull requestien automaattiseen katselmointiin branch policyn kautta. Ajakaa viikon pilotti yhdessä repossa ja verratkaa löydösten laatua, väärien hälytysten määrää ja kustannusta (AI-krediitit vs. tokenit).
