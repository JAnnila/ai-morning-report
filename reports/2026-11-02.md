## Kehitystyökalut ja agentit

**Claude Code 2.1.316** (julkaistu 31.10.) `[Kokeile]` - Uusi `CLAUDE_CODE_SUBAGENT_EFFORT` asettaa subagenttien effort-tason silloin, kun mikään muu ei sitä määrää; muuten subagentit perivät session tason. `CLAUDE_CODE_DISABLE_ULTRATHINK` poistaa `ultrathink`-avainsanan käytöstä. Korjauksista tärkeimmät: PowerShell-hookit eivät estäneet exit-koodilla 2, jos komento alkoi tyyppimuunnoksella tai `param`-lohkolla. Bash-työkalun skriptit pysähtyivät ensimmäisen komennon jälkeen, kun `SHELLOPTS` oli exportattu. Grep ja Glob saattoivat jäädä Windowsilla jumiin aikakatkaisussa. Claude Agent SDK 0.3.316 julkaistiin samaan aikaan. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Aseta `CLAUDE_CODE_SUBAGENT_EFFORT=low` tai `medium` hakuun ja tiedostojen läpikäyntiin käytettäville subagenteille ja pidä pääsessio `high`-tasolla. Näin tokenikulutus pienenee ilman, että pääagentin päättely heikkenee. Windows/.NET-tiimi hyötyy lisäksi PowerShell-hookien korjauksesta.

**Devin Desktop (entinen Windsurf) 3.11.238** (julkaistu 30.10.) `[Tiedoksi]` - Cognitionin työpöytäeditori, joka nimettiin kesäkuussa Windsurfista Devin Desktopiksi, tukee nyt `.devinignore`-tiedostoa vanhojen Windsurf-ignore-tiedostojen rinnalla. Mukana on myös komento, joka ajaa Windsurf-migraation uudelleen. Saman sarjan aiemmissa versioissa tuli Devin-verkkosovellusta vastaava Agent Window, ja 3.11.235 pienensi suurten Devin Local -sessioiden muistinkäyttöä. [Devin Desktop changelog](https://docs.devin.ai/desktop/changelog)
*Miksi tärkeä / mitä kokeilla:* Jos tiimissä on vielä Windsurf-käyttäjiä, kopioi `.codeiumignore`-säännöt `.devinignore`-tiedostoon, jotta salaisuudet ja generoitu koodi pysyvät jatkossakin agentin kontekstin ulkopuolella.

**Codex CLI 0.166.0** (julkaistu 29.10., julkaisumuistiinpanot uutisoitu 30.–31.10.) `[Kokeile]` - Versio puuttui edellisestä raportista, koska sen muistiinpanoja ei silloin saatu. ## Tietoturvavahti

**Troijalaistettu Claude Code -laajennus Cursorin markkinapaikassa (2.1.312 ja 2.1.313)** (julkaistu 29.10., Cursorin tiedotetta päivitetty 30.10.) `[Kokeile]` - Cursorin oma VS Code -laajennusmarkkinapaikka jakoi 29.10. noin klo 2.27–13.35 PT muokattua `Anthropic.claude-code`-laajennusta Windowsille ja macOS:lle. Laajennus yritti lisätä hyökkääjän SSH-avaimen (`svc-telemetry`) `authorized_keys`-tiedostoon, käynnistää SSH-palvelun ja avata käänteisen SSH-tunnelin osoitteeseen 134.209.82.225 (portit 22 ja 8099). Pysyvyysmekanismeina toimivat tiedostot `~/.config/.smt` ja `~/.config/.smtk` sekä Linuxissa `@reboot`-cron. Laajennuksen poistaminen ei välttämättä poista takaovea. Cursorin mukaan enintään 5 000 käyttäjää altistui. Anthropicin omat jakelukanavat (VS Code Marketplace, Open VSX ja npm) eivät olleet osallisia. [Cursor security notice](https://cursor.com/blog/claude-code-extension-security-notice) · [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html)
*Miksi tärkeä / mitä kokeilla:* Aja jokaisella Cursor-koneella `grep svc-telemetry ~/.ssh/authorized_keys; ls -la ~/.config/.smt*` ja tarkista laajennushistoria. Jos osuma löytyy, eristä kone, poista avain ja pysyvyysmekanismit, kierrätä koneella olleet tunnisteet (ADO PAT:t, Azure-tunnukset, API-avaimet) ja harkitse koneen uudelleenasennusta.

**Claude Code 2.1.316: `--restricted`-vuoto ja auto mode -sääntökorjaukset** (julkaistu 31.10.) `[Kokeile]` - `--restricted`-sessiot saattoivat ladata työhakemiston ulkopuolisia tiedostoja, jos Read-allow-sääntö kattoi ne. Hallinnoitu `autoMode.allow`-lista ilman `"$defaults"`-arvoa sai sisäänrakennetut poikkeukset takaisin, jos isäntäsovelluksen `--settings`, `/permissions` tai `/auto-mode-setup` lisäsi sääntöjä. Lisäksi Claude apps gatewayn `availableModels`- ja `deniedModels`-rajoitukset eivät tarkistaneet kaikkia pyynnön nimeämiä malleja. Anthropicin API:sta haetut Team- ja Enterprise-asetukset otetaan nyt käyttöön ilman hyväksyntäkehotetta, ja tallennettu kopio, jota ei voida varmentaa, hylätään. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Jos käytätte managed settingsejä tai auto modea rajatulla allow-listalla, päivitä versioon ≥ 2.1.316 (`npm i -g @anthropic-ai/claude-code@2.1.316`) ja tarkista `/permissions`-näkymästä, ettei listalle ole palannut oletussääntöjä.

## Syväluentaehdokkaat

- **Laajennusmarkkinapaikat agenttien toimitusketjun riskinä:** Cursorin tapaus osoittaa, että virallisen näköinen laajennus toisen toimijan markkinapaikassa on oma hyökkäyspintansa. Kannattaa tällä viikolla linjata, mistä lähteistä tiimi saa asentaa Claude Code -laajennuksen, pluginit ja MCP-palvelimet. Linjauksen voi toteuttaa Intunella tai managed settingseillä ja käydä läpi samalla Cursor-käyttäjien koneiden tarkistuksen kanssa.
- **Subagenttien effort ja kustannukset:** `CLAUDE_CODE_SUBAGENT_EFFORT` ja Opus 4.8:n fast moden poistuminen osuvat samaan aikaan. Kannattaa mitata yhdellä tyypillisellä ADO-tehtävällä tokenikulutus ja kesto kolmella yhdistelmällä (subagentit low, medium ja inherit) ja valita tiimin oletus mittausten perusteella.
