## Repot ja yhteisön tekniikat (mitä kokeilla)

**JuliusBrussee/caveman – Claude Code -skilli joka vähentää output-tokeneita ~65 % tiivistämällä lauserakennetta; 89 000+ GitHub-tähteä (julk. 2026, kehittäjähuomio kasvaa lokakuussa)**

Caveman on Claude Code -skilli joka käskee mallia vastaamaan telegraafisenglannilla: ei artikkeleita, ei siirtymälauseita, ei myöntelyä, ei varaumia. SKILL.md-tiedosto sisältää kuusi tiivistysvoimakkuustasoa ja SessionStart-hookin joka pitää ohjeen aktiivisena sessioiden yli. Kehittäjä väittää 65–75 %:n output-token-säästöä (v1.9.1 heinäkuulta yhtenäistää väitteen 65 %:iin, mitattu pelkästään output-tokeneista). Kritiikki: riippumaton analyysi (implicator.ai) huomauttaa, että benchmark mittaa väärää nimittäjää – useimmissa sessioissa output-tokenit ovat pieni osa kokonaiskuluista, ja yksi käyttäjä raportoi ~$1 säästön $100-tilauksella viikkokäytössä. Lisäetu: tiivis lauserakenne voi parantaa tarkkuutta monimutkaisissa tehtävissä (pasqualepillitteri.it viittaa maaliskuun 2026 arXiv-paperiin, tarkistamaton).

*Miksi tärkeä / mitä kokeilla:* Jos tiimisi käyttää Claude Code -agenttisessioita joissa output-virta on raskas (pitkät koodiselectiot, dokumentaatio), caveman on helpoin yksittäinen konfiguraatiomuutos testattavaksi. Asenna: `claude plugin marketplace add JuliusBrussee/caveman`. Testaa: aja kaksi identtistä agenttitehtävää – caveman päällä ja ilman – vertaa output-token-laskuria Claude-tilin käyttöpaneelissa. Jos output-tokenit ovat >30 % kokonaiskuluistasi, säästöpotentiaali on todellinen.

## Tietoturvavahti

**KRIITTINEN: GitLab CVE-2026-90970 CVSS 9.9 – AI Gateway RCE; autentikoitu käyttäjä voi paeta prompt-template-sandboxista ja ajaa komentoja palvelimella; ei korjausta ilman päivitystä (GitLab, julk. 2.10.2026; The Hacker News -kattavuus kasvaa)**

GitLab julkisti 2.10.2026 kriittisen haavoittuvuuden Duo Agent Platformin AI Gatewayssa (CVSS 9.9/10). Autentikoitu käyttäjä, jolla on Duo Agent Platform -oikeudet, voi lähettää muotoillun flow-konfiguraation joka murtautuu prompt-template-sandboxista ja ajaa mielivaltaisia komentoja gateway-palvelimella. Tekninen luonne: kyseessä on server-side template injection (SSTI), ei perinteinen prompt injection – haavoittuvuus on arkkitehtuuri-tason ongelma backend-template-moottorissa. Haavoittuvat versiot: 18.1.6 – 19.1.x (itsehostaukset). Korjattu versiot: 19.2.4, 19.3.2, 19.4.1. GitLab.com ja GitLab Dedicated jo paikattu – toimenpiteitä ei tarvita. Ei workaroundia päivittämättä. CISA: ei tiedossa aktiivista hyväksikäyttöä.

*Miksi tärkeä / mitä kokeilla:* CVSS 9.9 tarkoittaa käytännössä, että kukin autentikoitu GitLab-käyttäjä jolla on Duo Agent Platform -oikeudet voi saada palvelinpääsyn itsehostausympäristössä. Jos organisaatiosi ajaa itsehostattua GitLabia Duo Agent Platformin kanssa, päivitä välittömästi versioon 19.2.4+, 19.3.2+ tai 19.4.1+. Tarkista: `gitlab-rake gitlab:env:info | grep GitLab` – jos versio on alle 19.2.4, olet haavoittuvainen.
