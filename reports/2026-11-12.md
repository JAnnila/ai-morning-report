# AI-aamuraportti - 2026-11-12

## Päivän tärkeimmät

- Corelight julkaisi 10.11. tutkimuksen MCP-palvelinten riippuvuuksista: 35 tarkastetusta palvelimesta 23:n suositeltu asennustapa hakee riippuvuudet julkisesta rekisteristä joka käynnistyksellä, joten sama palvelinversio voi ajaa eri koodia eri päivinä. Lukitkaa MCP-palvelinten koko ympäristö, ei pelkkää versiota.
- OpenAI:n ehdottama päivämäärä mallien katkaisulle Cursorista on tänään 12.11. Jos tiimissä käytetään GPT-malleja Cursorin kautta, varautukaa siihen, että ne lakkaavat toimimasta (pilviagentit ja automaattinen mallivalinta eivät toimi omalla API-avaimella).
- Codex CLI 0.167.2 (11.11.) on uusi vakaa versio. Sen ainoa mainittu muutos on, että Vertex AI:ssa työkalupäivitykset lähetetään nyt oletuksena inkrementaalisesti.
- Gemini 4 Carbon on nyt maksullisessa Gemini API:ssa (`gemini-4-carbon`). Esittelyhinta $2/$10 per Mtok on voimassa 30.11. asti, minkä jälkeen se kaksinkertaistuu.
- Claude Codeen ei tullut uutta versiota 2.1.322:n (10.11.) jälkeen. Anthropicin päivitetty käyttöpolitiikka on voimassa tänään alkaen.

## Kehitystyökalut ja agentit

**Codex CLI 0.167.2** (julkaistu 11.11.) `[Tiedoksi]` - Uusi vakaa korjausversio (`latest`), joka julkaistiin vain päivä 0.167.1:n jälkeen. GitHub-julkaisun ainoa nostettu muutos on, että Google Cloud Vertex AI:ta käytettäessä Codex lähettää työkalupäivitykset nyt oletuksena inkrementaalisesti. Muuten julkaisussa on vain diff-linkki. Alpha-kanavassa on jo 0.170.0-alpha.2 (12.11.). *Miksi tärkeä / mitä kokeilla:* Jos ajatte Codexia Vertexin kautta, päivittäkää `npm i -g @openai/codex@0.167.2` ja tarkistakaa, että pitkät työkaluketjut toimivat. Muille päivitys ei ole kiireellinen.

**GitHub App -tuki Copilot-lisenssien hallintaan enterprise-tasolla** (julkaistu 10.11., uutisoitu 11.11.) `[Kokeile]` - Enterprise-tason GitHub Appit pääsevät nyt Copilotin lisenssienhallinnan API:hin uuden hienojakoisen oikeuden kautta, joten automaatio ei enää tarvitse henkilökohtaista PAT-tokenia. [GitHub Changelog](https://github.blog/changelog/2026-11-10-github-app-support-for-enterprise-copilot-seat-management/)
*Miksi tärkeä / mitä kokeilla:* Jos Copilot-lisenssejä jaetaan skriptillä tai Azure DevOps -putkesta adminin PAT:lla, siirtäkää se GitHub Appiin, jolla on pelkkä seat management -oikeus.

Muuta: GitHub Copilot CLI 1.0.109 julkaistiin 10.11. klo 17 UTC, eli juuri ennen tämän ajon ikkunaa, eikä sitä käsitelty eilen. Siinä tuli CIDR-tuki sandboxin host allow/deny -säännöille ja Fable 5.2 mallivalitsimeen. Lisäksi ACP-tilassa `preToolUse`-hookin `ask` välitetään nyt asiakkaalle, ja MCP-työkalujen base64-tekstitulokset tavoittavat mallin ([changelog](https://github.com/github/copilot-cli/blob/main/changelog.md)). Prerelease-sarja 1.0.110-x jatkuu (uusin 1.0.110-3, 12.11.). Claude Code (2.1.322) ja Claude Agent SDK (0.3.322) pysyivät ennallaan.

## Pluginit, skillit ja MCP

**MCP-palvelinten riippuvuusajelehtiminen: Corelightin mittaus** (julkaistu 10.11., uutisoitu 11.11.) `[Kokeile]` - Corelight kävi läpi 35 MCP-palvelinta kahdesta toimittajakatalogista ja omasta labrastaan. 23:n suositeltu asennus (esim. `npx`/`uvx` ilman lukitusta) hakee riippuvuudet julkisesta rekisteristä uudelleen. Labrakokeessa yhden kiinnitetyn version 19 buildia tuotti 15 erilaista ympäristöä, ja 69 paketista 23 vaihtoi versiota. Viisi jäädytettyä palvelinta pysyi identtisenä 457 käynnistyksen ajan kahden viikon aikana. Corelightin mukaan kyse on asennustavasta eikä MCP-protokollan viasta. [Corelight](https://corelight.com/blog/mcp-server-supply-chain-risk) · [GBHackers](https://gbhackers.com/corelight-reveals-ai-security/) · [Cybersecurity News](https://cybersecuritynews.com/hackers-could-exploit-mcp-server/)
*Miksi tärkeä / mitä kokeilla:* Käykää läpi `.mcp.json` ja `claude mcp list`. Korvatkaa `npx -y paketti` -tyyliset käynnistykset lukitulla asennuksella (lockfile + `npm ci`, tai kontti-image digestillä), ja antakaa jokaiselle palvelimelle oma, kapea tunniste.

Muuta: MCP-spesifikaatioon ja `@modelcontextprotocol/sdk`-pakettiin ei tullut uusia versioita (SDK yhä 1.32.2 / 23.10.). Show HN:ssä oli 11.11. työkalu, joka tekee mistä tahansa verkkosivusta MCP-palvelimen, mutta se ei herättänyt keskustelua eikä sille löytynyt primäärilähdettä.

## Toimintatavat ja arkkitehtuuripatternit

**MCP-palvelimen ympäristön jäädytys toimitusketjun kontrollina** (dokumentoitu 10.11.) `[Kokeile]` - Corelightin datasta saa suoraan sovellettavan käytännön: versio-pinni (`paketti@1.2.3`) ei riitä, koska transitiiviset riippuvuudet ratkaistaan uudelleen jokaisessa asennuksessa. Vain koko ympäristön jäädytys (lockfile, vendoroitu `node_modules` tai kontti-image) piti palvelimen sisällön samana kaikilla 457 käynnistyskerralla. Sama koskee Claude Code -pluginien ja skillien mukana tulevia MCP-palvelimia. [Corelight](https://corelight.com/blog/mcp-server-supply-chain-risk)
*Miksi tärkeä / mitä kokeilla:* Tehkää tiimin MCP-palvelimille oma repo, jossa jokaisella on lockfile ja Dockerfile. Rakentakaa imaget Azure DevOps -putkessa ja viitatkaa niihin `.mcp.json`:ssa digestillä (`image@sha256:...`).

**Koodikatselmointi siirtyy suunnitteluvaiheeseen** (julkaistu 9.11.) `[Seuraa]` - IT Revolutionin artikkeli käsittelee paperia "Agentic AI and Code Reviews". Sen mukaan agenttien tuottaman koodin pääasiallinen ihmiskatselmointi kannattaa tehdä suunnitelma- tai spesifikaatiovaiheessa, jolloin ihminen tarkistaa tarkoituksen ennen kuin koodia on olemassa. Koodivaiheessa nojataan erikoistuneisiin katselmointiagentteihin ja koordinaattoriin, joka kokoaa yhden duplikaateista karsitun kommenttisarjan. Esimerkkinä on Cloudflaren aiemmin julkaistu järjestelmä. [IT Revolution](https://itrevolution.com/articles/can-you-actually-trust-an-ai-agents-code-review/) · [Cloudflare: Orchestrating AI Code Review at scale](https://blog.cloudflare.com/ai-code-review)
*Miksi tärkeä / mitä kokeilla:* Kokeilkaa yhdessä tiimissä, että isommissa tehtävissä Claude Coden plan mode -suunnitelma tallennetaan PR:n liitteeksi (esim. `docs/plans/`) ja katselmoidaan ennen toteutusta. Koodikatselmointi tehdään sitten suunnitelmaa vasten.

## Tietoturvavahti

**Corelight: MCP-palvelimet ajavat tarkastamatonta koodia etuoikeutetuilla tunnisteilla** (julkaistu 10.11., uutisoitu 11.11.) `[Kokeile]` - Tietoturvanäkökulma samaan tutkimukseen: MCP-palvelimilla on usein pääsy API-avaimiin ja admin-tunnisteisiin. Jos julkisesta rekisteristä haettu transitiivinen riippuvuus kaapataan, haitallinen koodi päätyy kehittäjän koneelle seuraavalla käynnistyksellä ilman uutta asennusta tai katselmointia. Tutkitulta työasemalta ei löytynyt haittakoodia. Kyse on altistuksesta, ei havaitusta hyökkäyksestä. [GBHackers](https://gbhackers.com/corelight-reveals-ai-security/) · [Corelight](https://corelight.com/blog/mcp-server-supply-chain-risk)
*Miksi tärkeä / mitä kokeilla:* Inventoikaa, mitä salaisuuksia (ADO PAT, Azure-tunnisteet, tietokantayhteydet) MCP-palvelimien `env`-kentissä on. Siirtäkää ne lyhytikäisiin, kapeisiin tunnisteisiin ja rajatkaa palvelimien ulosmenevä liikenne sallittujen listaan.

Muuta: Uusia CVE:itä agenttien, MCP:n tai kehitystyökalujen osalta ei löytynyt ikkunasta eilen raportoitujen VS Code -korjausten jälkeen.

## Hinnoittelu, saatavuus ja sääntely

**OpenAI-mallien katkaisu Cursorista, määräpäivä tänään 12.11.** (uutisoitu 29.8., määräpäivä 12.11.) `[Seuraa]` - SpaceX:n ostettua Cursorin OpenAI ilmoitti lopettavansa mallien toimittamisen Cursorille ja ehdotti siirtymän päättymispäiväksi 12.11. Lähteet ovat eri mieltä siitä, onko päivä lopullinen. Omalla OpenAI-API-avaimella mallit toimivat vain paikallisessa Chatissa ja Agentissa, eivät pilviagenteissa eivätkä automaattisessa mallivalinnassa. Cursorin muut mallit eivät muutu. [CNBC](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html) · [Digital Applied](https://www.digitalapplied.com/blog/openai-ends-cursor-model-access-november-cutoff)
*Miksi tärkeä / mitä kokeilla:* Jos joku tiimissä käyttää Cursoria GPT-malleilla tai Cursorin pilviagentteja, vaihtakaa mallivalinta Claude- tai Gemini-malliin jo nyt, jotta työnkulku ei katkea kesken.

**Anthropicin päivitetty käyttöpolitiikka voimaan 12.11.** (julkaistu aiemmin, voimaan 12.11.) `[Tiedoksi]` - Politiikka tarkentaa ase- ja valvontakieltoja ja lisää kiellon pitkäkestoisesta, mallia kohtaan suunnatusta loukkaavasta käytöksestä. Tavalliseen ohjelmistokehitykseen sillä ei ole vaikutusta. Asiakkaille tarjottavien agenttituotteiden ehdot kannattaa kuitenkin tarkistaa sitä vasten. [Anthropic](https://www.anthropic.com/news/2026-usage-policy-update)
*Miksi tärkeä / mitä kokeilla:* Jos rakennatte Claude-pohjaista agenttia asiakkaiden käyttöön, välittäkää tieto tuotteen käyttöehdoista vastaavalle.

Muistutukset: Copilot poistaa Claude Opus 4.8:n, Claude Opus 5:n ja GPT-5.6 Terran 16.11. Gemini 4 -mallien hinnat nousevat 1.12. OpenAI:n Agent Builder ja Opus 4.8:n fast mode poistuvat 30.11.

## Syväluentaehdokkaat

- **MCP-palvelinten jäädytys ja tunnisteet:** Corelightin mittaus antaa konkreettiset luvut riskille, jonka moni tiimi on ohittanut: `npx`-tyylinen asennus ajaa eri koodia eri päivinä. Varatkaa tällä viikolla tunti tiimin `.mcp.json`-tiedostojen läpikäyntiin, siirtäkää palvelimet lukittuihin imageihin ja kapeisiin tunnisteisiin, ja kirjatkaa tulos tiimin MCP-sallittujen listaan.
- **Suunnitelman katselmointi ennen koodia:** IT Revolutionin käsittelemä malli (ihminen katselmoi suunnitelman, agentit koodin) sopii suoraan Claude Coden plan modeen. Kokeilkaa sitä yhdessä sprintissä ja mitatkaa, väheneekö PR-katselmointiin kuluva aika ja uudelleentyö.
