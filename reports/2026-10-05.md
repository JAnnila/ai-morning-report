## Tietoturvavahti

**KRIITTINEN: "Explosive prompts" – piilotettu ehdollinen injektio onnistuu 43–83% ajasta Claude Codessa, Codexissa, Gemini CLI:ssä, Cursorissa, GitHub Copilotissa (Adversa AI, julk. ~3.–4.10.2026)**

Adversa AI:n lokakuun 2026 turvaraportti dokumentoi uuden uhkaluokan: "explosive prompts" ovat dormant conditional injections jotka pysyvät piilossa kunnes attacker-valittu laukaisusana esiintyy agentin kontekstissa – sitten injektio suorittuu heti. Menestysprosentti tutkituilla agenteilla: Claude Code 43–53%, Codex ~55%, Gemini CLI ~61%, Cursor ja GitHub Copilot jopa 83% – verrattuna alle 3%:iin tavallisilla pakotetuilla injektioilla. Rakenne ehtolauseena ei näytä haitalliselta – staattiset reposkannerit eivät löydä näitä. Raportti kattaa myös GitSpawn (git config RCE, 4 edelleen paikkaamatonta, mukaan lukien toinen variantti Claude Codessa) ja PixelLeak.

*Miksi tärkeä / mitä kokeilla:* Explosive prompts muuttaa uhkamallin: riittää että koodipohja sisältää ehdollisen ohjeen joka aktivoituu vain oikealla hetkellä. Nykyiset staattiset analyysityökalut eivät löydä näitä. Toimenpide: tarkasta että Claude Code -ympäristösi skills-paketit ja MCP-serverit tulevat verifioiduista lähteistä; älä kloonaa tuntemattomia repoja agentti-sessioissa ilman eristystä.

**PixelLeak – 13 000 sisäistä screenshottia 300+ organisaatiosta vuoti julkisiin GitHub-repositorioihin (Glow Security, ~3.–4.10.2026)**

Glow Security havaitsi AI-koodausagenttien vuotaneen 13 000+ sisäistä screenshottia yli 300 organisaatiosta julkisiin GitHub-repoihin. Juurisyy: GitHub CLI:n v2.99.0 (1.9.2026) lisäämä image-attachment-tuki puuttui aiemmista versioista – agenteilla ei ollut tapaa liittää kuvia PR:iin CLI:n kautta, joten ne latasivat ne erillisiin julkisiin repositorioihin. 93% tapauksista repositorio oli työntekijän henkilökohtaisen käyttäjätilin alla, joten yrityksen turvallisuustiimi ei löytänyt niitä. Altistunutta: laskutustiedot, julkaisemattomat ominaisuudet, sisäiset talouskonsoli-näkymät.

*Miksi tärkeä / mitä kokeilla:* Varmista että kaikki tiimisi AI-koodausagentit käyttävät GitHub CLI:n versiota ≥ 2.99.0. Tarkasta myös onko tiimin jäsenten henkilökohtaisissa GitHub-tileissä epäilyttäviä julkisia repositorioita syys–lokakuulta 2026.
