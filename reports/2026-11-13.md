# AI-aamuraportti - 2026-11-13

## Päivän tärkeimmät

- Claude Code 2.1.323 (12.11.) toi kokeellisen Code Moden: Claude kirjoittaa JavaScriptiä, joka kutsuu sen työkaluja, eikä tee kutsuja yksi kerrallaan. Ominaisuus on opt-in, ja organisaatio voi kytkeä sen pois.
- Sama julkaisu korjasi useita lupamallin aukkoja, mm. `Bash(ls*)`-tyyliset jokerisäännöt, jotka ohittivat kyselyn, ja Bash-sandboxin, joka saattoi kytkeytyä pois kesken session. Päivittäkää kaikki koneet ja CI-ajot.
- Pluginit voivat nyt ilmoittaa `plugin.json`-tiedostossa tuetun Claude Code -versioalueen (`engines["claude-code"]`), ja `claude plugin validate` tyyppitarkistaa TypeScript-hookit. Tämä on hyödyllistä tiimin omille plugineille.
- Codex CLI 0.168.0 julkaistiin vakaana tänä aamuna (13.11.), ja GitHub Copilot CLI 1.0.110 (12.11.) toi kokeellisen maskatun dialogin git-, ssh- ja sudo-salasanakyselyille.
- Google julkaisi Gemini Decision 1 -mallin (11.11.). Se ei generoi tekstiä vaan arvioi syötteen jopa 1 000 kysymystä vasten yhdellä kertaa, mikä tekee siitä halvan vaihtoehdon LLM-luokittelijoille ja -tuomareille.

## Pluginit, skillit ja MCP

**Plugin-manifestin `engines["claude-code"]` ja hookien tyyppitarkistus** (julkaistu 12.11.) `[Kokeile]` - Claude Code 2.1.323:sta alkaen plugin voi ilmoittaa `plugin.json`-tiedostossa, mitä Claude Code -versioita se tukee. Alueen ulkopuolella pluginia ei asenneta, päivitetä eikä ladata, ja asennus valitsee uusimman version, joka sopii alueeseen. `claude plugin validate` tyyppitarkistaa nyt pluginin TypeScript-hookit (varoituksina; `--strict` kaataa validoinnin), ja `claude plugin install --json` palauttaa `unsetOptionCount`-kentän asettamattomista `userConfig`-arvoista. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Lisätkää tiimin omiin plugineihin `"engines": {"claude-code": ">=2.1.323"}` ja ajakaa `claude plugin validate --strict` Azure DevOps -putkessa ennen kuin plugin julkaistaan sisäiseen marketplaceen.

Muuta: MCP-spesifikaatioon ja `@modelcontextprotocol/sdk`-pakettiin ei tullut uutta (yhä 1.32.2 / 23.10.). Uusia toimittajakohtaisia MCP-palvelimia ilmestyi (mm. OnePlan preview, Outlier), mutta ne eivät koske tiimin kehitystyötä.

## Toimintatavat ja arkkitehtuuripatternit

**Code Mode: työkalukutsut skriptinä yksittäisten kutsujen sijaan** (julkaistu 12.11.) `[Kokeile]` - Code Modessa malli kirjoittaa yhden JavaScript-ohjelman, joka kutsuu työkaluja, ja vain lopputulos palaa kontekstiin. Välitulokset, kuten pitkät tiedostolistaukset tai MCP-vastaukset, jäävät pois. Pattern on yhteisössä tunnettu (useita Claude Code -modeja, esim. gabe4coding/claude-code-mode), mutta nyt se on sisäänrakennettu ja organisaatiotasolla hallittava. Community-toteutusten mukaan skriptin sisäiset kutsut kulkevat samojen lupasääntöjen läpi kuin mallin omat kutsut. Virallista dokumentaatiosivua ei saatu luettua, joten tarkistakaa tämä itse ennen laajaa käyttöä. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · [gabe4coding/claude-code-mode](https://github.com/gabe4coding/claude-code-mode)
*Miksi tärkeä / mitä kokeilla:* Ottakaa Code Mode käyttöön yhdellä kehittäjällä tehtävään, jossa on paljon MCP-kutsuja (esim. ADO-työjonon läpikäynti), ja vertailkaa `/context`- ja `/usage`-lukemia ilman Code Modea tehtyyn ajoon.

Muuta: LangChainin 2.11. postaus asynkronisista subagenteista on käsitelty aiemmin. Uusia, konkreettisia ja päivättyjä käytäntökirjoituksia ei 7 vuorokauden ikkunasta löytynyt muita.

## Tietoturvavahti

**Claude Code 2.1.323: lupamallin ja sandboxin korjaukset** (julkaistu 12.11.) `[Kokeile]` - Julkaisu korjasi useita aukkoja, joissa komento saattoi ohittaa kyselyn:
- Bash-sallintasäännöt, joissa jokeri on kiinni nimessä (`Bash(ls*)`), ohittivat kyselyn osassa tapauksia. Muuttujan nimeävä sääntö (`Bash(NODE_ENV*)`) kysyy nyt.
- Bash-sandbox saattoi kytkeytyä pois kesken session.
- `rm`-tarkistus tehtiin väärästä hakemistosta bypass-tilassa tai allow-säännön alla.
- Osa `lsof`-komennoista ajettiin ilman kyselyä.
- "Don't ask again" tarjottiin `.git`- ja `.claude`-polkuihin kirjoittaville komennoille, vaikka tallennettu sääntö ei toiminut.
- `--permission-mode auto` käynnistyi sallivampaan tilaan, kun auto mode ei ollut saatavilla. Nyt se käynnistyy Manual-tilaan.

Lisäksi `plansDirectory`-asetuksella suunnitelmatiedostot saattoivat päätyä projektin ulkopuolelle, ja käynnistyksessä varoitetaan nyt säännöistä kuten `Bash(PORT=* npm run dev)`. [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Päivittäkää versioon 2.1.323. Etsikää sitten `grep -rn 'Bash([^)]*\*' ~/.claude .claude` ja korvatkaa kiinni olevat jokerit välilyönnillisellä muodolla (`Bash(ls *)`) tai tarkemmilla säännöillä.

Muuta: Uusia CVE:itä agenttien, MCP:n tai kehitystyökalujen osalta ei löytynyt ikkunasta. Adversan marraskuun kooste on käsitelty aiemmin.

## Syväluentaehdokkaat

- **Code Mode tiimin MCP-raskaissa työnkuluissa:** Code Mode voi pienentää kontekstin kulutusta selvästi juuri niissä tehtävissä, joissa tiimi ketjuttaa ADO- ja Azure-MCP-kutsuja. Lukekaa virallinen dokumentaatio, tarkistakaa miten lupasäännöt ja sandbox koskevat skriptin sisäisiä kutsuja, ja tehkää yksi mitattu A/B-ajo ennen kuin päätätte organisaation oletusasetuksesta.
- **Lupasääntöjen auditointi 2.1.323:n jälkeen:** Kun jokerisääntöjen ja sandboxin käytös muuttui, nykyiset `settings.json`-allow-listat kannattaa käydä läpi kerralla. Samalla kannattaa lisätä tiimin plugineihin `engines`-rajaus, jotta vanhat Claude Code -versiot eivät lataa niitä.
