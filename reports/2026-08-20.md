**Grok 4.6 saatavilla Amazon Bedrockissa (xAI + AWS, ann. 19.8.2026)**

## Repot ja yhteisön tekniikat (mitä kokeilla)

**Claude Code v2.1.236 (19.8.2026) – ANTHROPIC_DEFAULT_MODEL, cross-session idle-ilmoitukset, macOS-hiekkalaatikon tiukennus**

Anthropic julkaisi Claude Coden version 2.1.236 19.8. Tärkeimmät kehittäjälle näkyvät muutokset:

- **`ANTHROPIC_DEFAULT_MODEL`**: Uusi ympäristömuuttuja joka asettaa mallin jolla uudet sessiot käynnistyvät. Eroaa `ANTHROPIC_MODEL`-muuttujasta: `/model`-komennolla tehty valinta ohittaa sen ja pysyy voimassa uudelleenkäynnistysten välillä, toisin kuin `ANTHROPIC_MODEL`. Käyttötapaus: eri projektihakemistoissa eri oletusmallit projektitason `.env`-tiedostoilla.
- **`notify_when_idle` cross-session SendMessage -kutsussa**: Mahdollistaa kysyä toiselta Claude Code -sessiolta samalla koneella ilmoitusta heti kun se seuraavan kerran vapautuu. Opt-in, kertakäyttöinen, ilman pollausta – saatavilla macOS:ssa ja Linuxissa.
- **macOS-hiekkalaatikon tiukennus** (ks. myös Tietoturvavahti): Wildcard read-deny-säännöt (esim. `**/.env`, `**/.ssh`) ottavat nyt ylivoimaisen prioriteetin sallittuihin luku-alueisiin nähden, kattavat hakemistojen sisällöt, eikä niitä voi kiertää nimeämällä tiedostoa uudelleen.
- **Bugikorjaukset**: Notification hooks eivät laukenneet lupakyselyissä Claude Desktopin tai VS Coden alla; idle-sessiot Linuxilla pitivät yhtä prosessoritumaa 100 %:ssa sandboxingin kanssa.
- **Palautus**: 2.1.232:n Bash-oikeusmuutokset Cygwin-tyylisille symlinkille Windowsissa ja input-uudelleenohjauksille on palautettu – ne aiheuttivat regressioita.

*Miksi tärkeä / mitä kokeilla:* `ANTHROPIC_DEFAULT_MODEL` mahdollistaa projektikohtaisen mallioletuksen `.env`-tiedostossa ilman `settings.json`-konfiguraatiota – testaa asettamalla `ANTHROPIC_DEFAULT_MODEL=claude-opus-5` korkean päättelykyvyn vaativalle projektille ja `claude-haiku-4-5-20251001` nopean vasteen projektille. `notify_when_idle` sopii pitkien rinnakkaisten ajojen koordinointiin: käynnistä pitkä ajo sessiossa A, rekisteröi idle-ilmoitus sessiosta A sessioon B – ei pollausta.

## Tietoturvavahti

**Claude Code v2.1.236: macOS-hiekkalaatikon wildcard-deny-sääntöjen tiukennus sulkee GhostApproval-tyyppisen kiertotien (19.8.2026)**

Saman 2.1.236-päivityksen tietoturvaosa (ks. Repot-osio): wildcard-tyylinen deny-sääntö (esim. `**/.env`) ottaa nyt käyttöön ehdottoman etusijan suhteessa sallittuihin luku-alueisiin macOS-hiekkalaatikossa. Aiemmin hyökkääjä saattoi kiertää deny-säännön nimeämällä kiellettyjä tiedostoja uudelleen – tämä polku on nyt suljettu. Muutos on suoraan vastaus GhostApproval-tyylisille hyökkäyksille (Wiz Research, julk. 8.7.2026), joissa haitallinen symlink-tiedosto paketissa voi johtaa agenttia kirjoittamaan tiedostoja työtilan ulkopuolelle tai lukemaan arkaluonteisia tiedostoja kuten SSH-avaimia.

Huomio: Augment ja Windsurf ovat edelleen paikkaamatta GhostApproval-haavoittuvuuden osalta (Wiz, 8.7.2026). Jos tiimisi käyttää näitä työkaluja, käytä vain luotettuja repositorioita kunnes korjaukset julkaistaan.

*Miksi tärkeä / mitä kokeilla:* Tarkista Claude Code -projektikohtaiset deny_paths-konfiguraatiot – v2.1.236 jälkeen wildcard-säännöt toimivat kuten odotettiin. Jos olet aiemmin lisännyt manuaalisia kiertotien estoja, ne ovat nyt tarpeettomia. Päivitä Claude Code uusimpaan versioon (2.1.236+) ennen töihin tuomista haavoittuvien repositorioiden kanssa.

[Claude Code changelog – code.claude.com](https://code.claude.com/docs/en/changelog) | [Wiz: GhostApproval vulnerability](https://www.wiz.io/blog/ghostapproval-a-trust-boundary-gap-in-ai-coding-assistants)

## Saatavuus- ja sääntelyriskit

**Gemini Enterprise: A2A v1.0 ja A2UI v0.9 agenttirekisteröinti GA – Googlen avoin agenttiprotokolla vakiintuu (Google, ann. ~19.8.2026)**

Google teki Gemini Enterprisen A2A- (Agent-to-Agent) ja A2UI- (Agent-to-UI) agenttirekisteröintiominaisuuden yleisaatavilla (GA) noin 19.8. Muutokset:
- A2A-protokolla **v1.0** tuki: kehittäjät voivat nyt eksplisiittisesti julistaa transport-endpointit ja bindinit `supportedInterfaces`-taulukossa (aiemmin vain 0.3-skeema)
- A2UI **v0.9** tuki v0.8:n rinnalle, uusilla Material Design -komponenteilla mukautettuja käyttöliittymiä varten
- Google Cloud Marketplace -agenttien rekisteröinti suoraan Gemini Enterprise -ympäristöön on nyt GA

A2A v1.0:n GA on merkittävä signaalit: se on ensimmäinen vakaa versio Googlen avoimesta agenttiprotokollasta, mikä tarkoittaa SLA-tukea ja pitkäaikaista yhteensopivuustakuuta. A2A on Googlen johtama avoin standardi (github.com/google/A2A) jota tukevat jo yli 50 kumppania (AWS, Microsoft, SAP, Atlassian ym.) – v1.0 on nyt se versio johon kannattaa rakentaa.

*Miksi tärkeä / mitä kokeilla:* Jos suunnittelet multi-vendor agenttiarkkitehtuuria (Gemini + Claude Code + ulkopuoliset agentit), A2A v1.0 on nyt dokumentoitu ja SLA-tuettu standardi eikä enää liikkuva maali. Tarkista A2A 0.x-integraatioiden yhteensopivuus v1.0-skeeman kanssa – explicit transport-bindingit ovat merkittävä muutos. Selaa Google Cloud Marketplace -agenttirekisteriä löytääksesi valmiiksi sertifioituja kolmannen osapuolen agentteja.
