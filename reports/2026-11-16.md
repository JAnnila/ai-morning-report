# AI-aamuraportti - 2026-11-16

## Päivän tärkeimmät

- Codex CLI 0.169.0 (13.11.) muuttaa CI-ajoja: `codex exec` ja `codex review` eivät enää lataa projektin konfiguraatiota eivätkä MCP-palvelimia hakemistossa, jota ei ole merkitty luotetuksi, ja luottamus tallennetaan uudella `--trust`-lipulla.
- Claude Code 2.1.325 (13.11.) korjasi zstd-pakattujen vastausten tietoturvaongelman sekä bugin, jossa claude.ai-kirjautumisella käynnistetyt taustasessiot käyttivät ja laskuttivat shellin API-avainta. Päivittäkää.

- Google julkaisi Gemini 4 Hydrogenin (12.11.), joka korvaa Flash-tason ($1,50 / $7,50 per milj. tokenia). Malli tuli GitHub Copilotiin 13.11.
- Copilot poistaa tänään (16.11.) Claude Opus 4.8:n, Claude Opus 5:n ja GPT-5.6 Terran käytöstä kaikissa Copilot-pinnoissa. Tarkistakaa tiimin oletusmallit.

## Pluginit, skillit ja MCP

**Claude Code 2.1.325: MCP Tasks- ja elicitation-korjaukset** (julkaistu 13.11.) `[Kokeile]` - Korjaukset parantavat 2.1.32x:ssä tulleiden MCP Tasksien luotettavuutta:
- Tehtävä ei enää jumiudu, jos sen kysymys suljetaan Escillä. Footer kertoo, että tehtävä odottaa syötettä, ja `/tasks`-näkymässä Enter näyttää kysymyksen uudelleen.
- Taustatehtävät jatkavat päivittymistä yhteyskatkon jälkeen.
- Kysymys ei enää aukea kesken kirjoitetun viestin päälle.
- Headless-tilassa elicitation-pyyntöjä ei enää peruta kysymättä, kun yhteys vaihtuu kesken työkalukutsun.
- MCP-palvelin ei enää jää "needs authentication" -tilaan hetkellisesti hylätyn token-päivityksen jälkeen (myös `mcp_tool`-hookit ajetaan taas).

[CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
*Miksi tärkeä / mitä kokeilla:* Jos käytätte Azure DevOps- tai Azure-MCP:tä pitkien taustatehtävien kanssa, ajakaa yksi pitkä tehtävä uudelleen 2.1.325:llä ja katsokaa, palautuuko se verkkokatkosta.

**Copilot CLI 1.0.112: workspace-MCP:n luottamusvaroitukset** (julkaistu 13.11.) `[Tiedoksi]` - Kun prompt-tila ja MCP-tarkastelukomennot ohittavat työtilan MCP-konfiguraation, koska kansio ei ole luotettu, ne kertovat nyt mikä konfiguraatio ohitettiin (myös ylähakemistoista) ja minkä kansion luottaminen sen lataisi. MCP:n system prompt -katselmoinnit näytetään pelkkänä tekstinä, joten terminaalin ohjausmerkit eivät voi muotoilla, linkittää tai piilottaa sisältöä. [changelog](https://github.com/github/copilot-cli/blob/main/changelog.md)
*Miksi tärkeä / mitä kokeilla:* Ajakaa `copilot mcp list` repossa, jossa on `.mcp.json`, ja varmistakaa, ettei luottamattoman kansion palvelimia ladata huomaamatta.

Muuta: MCP-spesifikaatioon ja `@modelcontextprotocol/sdk`-pakettiin ei tullut uutta (yhä 1.32.2 / 23.10.).

## Toimintatavat ja arkkitehtuuripatternit

**Eksplisiittinen projektiluottamus valvomattomissa agenttiajoissa** (julkaistu 9.11., toteutui 0.169.0:ssa 13.11.) `[Kokeile]` - Codex 0.169.0:sta alkaen ei-interaktiiviset ajot (`codex exec`, `codex review`) eivät lataa projektin `.codex/`-konfiguraatiota eivätkä MCP-palvelimia hakemistossa, jota ei ole merkitty luotetuksi. Tämä pätee myös `--sandbox workspace-write`-tilassa. Luottamus tallennetaan eksplisiittisesti `--trust`-lipulla. Pattern on sama kuin Claude Coden ja Copilot CLI:n workspace trust: repon mukana tuleva agenttikonfiguraatio on hyökkäyspinta (vrt. keyv-matoon, joka istutti hookeja `.claude/settings.json`-tiedostoon), joten CI:n pitää päättää siitä tietoisesti. Daniel Vaughan kuvaa CI/CD-vaikutukset ja migraation koodiesimerkein. [Release 0.169.0](https://github.com/openai/codex/releases/tag/rust-v0.169.0) · [Codex CLI in CI/CD: explicit project trust](https://codex.danielvaughan.com/2026/11/09/codex-ci-cd-non-interactive-trust-explicit-project-trust-flag/)
*Miksi tärkeä / mitä kokeilla:* Lisätkää Azure DevOps -putkien Codex-askeliin `--trust` vain omille repoille, älkää ulkopuolisille PR-haaroille. Tarkistakaa samalla, että Claude Code -putkissa on vastaava rajaus (esim. `--setting-sources` tai erillinen hallittu konfiguraatio).

Muuta: Muut 7 vuorokauden ikkunasta löytyneet context engineering- ja spec-driven-kirjoitukset olivat yleiskatsauksia ilman uutta konkreettista tekniikkaa tai päiväystä. Thoughtworksin Radar-merkintä subagenteista (4.11.) jää ikkunan ulkopuolelle.

## Uudet mallit

**Gemini 4 Hydrogen** (julkaistu 12.11., Copilotissa 13.11.) `[Kokeile]` - Googlen uusi nopea malli korvaa Flash-tason. Se on yleisesti saatavilla Gemini API:ssa ja on mediatietojen mukaan noin 2,5 kertaa nopeampi kuin Gemini 3.8 Flash. Hinta on $1,50 / $7,50 per miljoona tokenia koko 1M-kontekstissa, välimuistisyöte $0,075 ja batch/flex $0,75 / $3,75. Token-hinta on kaksinkertainen 3.8 Flashin kampanjahintaan verrattuna, mutta Artificial Analysisin mittauksessa tehtäväkohtainen kustannus oli pienempi ($1,87 vs. $7,77). Synkronisen ulostulon kerrotaan rajoittuvan 64K tokeniin. GitHub Copilotissa malli on yleisesti saatavilla 13.11. alkaen. [GitHub Changelog](https://github.blog/changelog/2026-11-13-gemini-4-hydrogen-in-github-copilot/) · [MarkTechPost](https://www.marktechpost.com/2026/11/13/google-gemini-4-hydrogen/) · [VentureBeat](https://venturebeat.com/technology/google-launches-gemini-4-hydrogen-a-faster-smarter-pricier-flash-successor)
*Miksi tärkeä / mitä kokeilla:* Kokeilkaa Hydrogenia Copilotissa nopeisiin rutiinitehtäviin ja vertailkaa sitä Claude-malleihin. Jos käytätte Gemini API:a, mitatkaa tehtäväkohtainen kustannus ennen kuin 3.8 Flashin hinta nousee 1.1.2027.

Muuta: GPT-6.2:n ja Grok 4.8:n huhutut julkaisuikkunat eivät toteutuneet viikonloppuna vahvistetusti. Ne jätettiin pois.

## Syväluentaehdokkaat

- **Valvomattomien agenttiajojen luottamusmalli yhtenäiseksi:** Codex 0.169, Copilot CLI 1.0.112 ja Claude Code käsittelevät nyt kaikki repon mukana tulevaa agenttikonfiguraatiota (MCP, hookit, asetukset) luottamuspäätöksenä. Kokeilkaa sitä yhdellä oikealla monikerroksisella featurella (.NET + Angular + testit) ja kirjatkaa, missä koordinaattori jää jälkeen omasta orkestroinnista.
