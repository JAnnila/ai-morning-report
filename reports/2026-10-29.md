# AI-aamuraportti - 2026-10-29

## Päivän tärkeimmät

- GitHub Universe (28.10.) toi Copilotiin jaetut Automations-työnkulut, VS Coden Agent Hostin ja avoimen Agent Host Protocol 1.0:n sekä laitteiden välillä jatkuvat cloud-sessiot.
- Copilot Fusion osaa nyt reitittää paikallisten (esim. Ollama) ja pilvimallien välillä Copilot CLI:ssä, Copilot-appissa ja VS Codessa (kokeellinen).
- Microsoft julkaisi Foundry Agent Serviceen hallitun Copilot-harnessin (public preview, maksuton 1.12. asti); pitkäkestoisten hosted-agenttien uudelleenkäynnistys on nyt GA.
- GitHub Enterprise Cloud -lisenssiin sisältyy nyt Copilot-pääsy, ja Copilot Standalone maksaa $10/käyttäjä/kk; AI-käyttö laskutetaan ensimmäisestä pyynnöstä yritysbudjetista.
- Kriittinen CVE-2026-93328 (CVSS 9.3) Googlen MCP Toolbox for Databasesissa: päivitä versioon 1.5.0, jos käytät sitä.

## Kehitystyökalut ja agentit

**GitHub Copilot in VS Code: Universe-julkaisut** (julkaistu 28.10.) `[Kokeile]` - Agent Host ajaa Copilot-sessiot erillisessä prosessissa, joten työ jatkuu taustalla ikkunan sulkemisen jälkeen. Cloud-sessiot pyörivät GitHubin infrassa, ja saman session voi jatkaa VS Codessa, Copilot-appissa, GitHub Mobilessa, github.comissa tai Copilot CLI:ssä (kokeellinen). Lisäksi mukana on kokeellinen computer use macOS:lle ja Windowsille; jokainen sovellus vaatii erillisen hyväksynnän, ja organisaatio voi estää ominaisuuden policyllä. [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-copilot-in-vs-code-universe-releases/) · [VS Code Wrapped](https://code.visualstudio.com/blogs/2026/10/28/vscode-wrapped)
*Miksi tärkeä / mitä kokeilla:* Käynnistä pitkä refaktorointi cloud-sessiona VS Codessa ja jatka sitä Copilot CLI:stä, niin näet, korvaako se omat tmux- ja worktree-viritykset.

**Copilot Automations: jaetut tiimityönkulut** (julkaistu 28.10.) `[Kokeile]` - Repossa määriteltävät AI-työnkulut ajetaan pilvessä käsin, tapahtumasta tai ajastettuna. Ne voivat nyt oppia lopputuloksistaan ja ehdottaa parannuksia, jotka ihminen hyväksyy. VS Coden Agents-ikkunassa automaatiot ovat oletuksena päällä, ja ominaisuus leviää Pro-, Pro+-, Max-, Business- ja Enterprise-tilauksiin. [GitHub Changelog](https://github.blog/changelog/2026-10-28-build-shared-workflows-for-your-team-with-copilot-automations/)
*Miksi tärkeä / mitä kokeilla:* Vertaa yöllisen "päivitä riippuvuudet ja avaa PR" -ajon toteutusta Automationsina nykyiseen Claude Code Routine- tai Azure Pipelines -toteutukseen.

**Copilot Fusion: paikallisten mallien reititys** (julkaistu 28.10.) `[Kokeile]` - Fusion valitsee laitteella ajettavan ja pilvimallin välillä Copilot CLI:ssä, Copilot-appissa ja VS Codessa (kokeellinen preview). CLI löytää ladatut Ollama-mallit automaattisesti, mutta BYOK-mallit eivät ole Fusion-kelpoisia automaattisesti. JetBrainsissa Fusion korvaa Auto-mallivalinnan. [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-copilot-fusion-now-supports-selection-of-local-models/) · [Docs](https://docs.github.com/en/copilot/concepts/models/copilot-fusion)
*Miksi tärkeä / mitä kokeilla:* `copilot --experimental` (tai `/experimental on`) ja Ollamalla ladattu paikallinen malli: mittaa, kuinka suuri osa rutiinipyynnöistä jää koneelle ja paljonko AI-krediittejä säästyy.

**Copilot Memory GA ja "dreaming" (public preview)** (julkaistu 28.10.) `[Kokeile]` - Copilot Memory on yleisesti saatavilla maksullisissa tilauksissa. Opt-in-ominaisuus dreaming käy läpi aiempaa työtä ja ehdottaa henkilökohtaisen muistin, repositorion ohjeistuksen ja koodikatselmoinnin ohjeiden päivityksiä. Organisaatio ottaa sen käyttöön Copilot-policyllä. [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-intelligence-puts-your-code-context-and-history-to-work/)
*Miksi tärkeä / mitä kokeilla:* Sama idea kuin CLAUDE.md:n ylläpito agentin omista havainnoista; kokeile yhdessä repossa ja katso, ovatko ehdotetut ohjemuutokset hyväksymiskelpoisia.

**Microsoft Copilot harness Foundry Agent Servicessä** (julkaistu 28.10.) `[Kokeile]` - Microsoft ajaa agenttisilmukan ja sandboxin, ja kehittäjä tuo ohjeet, skillit, työkalut ja mallivalinnan (public preview). Käyttö on maksutonta 1.12.2026 asti, minkä jälkeen alkaa kulutuspohjainen laskutus. Olemassa olevaa agenttia ei voi vaihtaa harnessiin jälkikäteen, ja Microsoft varoittaa, että yksinkertaisissa tehtävissä harness lisää viivettä ja Copilot Credit -kulutusta. [Microsoft Foundry Blog](https://devblogs.microsoft.com/foundry/microsoft-copilot-harness-in-foundry/)
*Miksi tärkeä / mitä kokeilla:* Azure-tiimille matalan kynnyksen tapa ajaa pitkäkestoisia agentteja ilman omaa infraa; kokeile yhtä taustatehtävää ennen joulukuun laskutuksen alkua.

## Pluginit, skillit ja MCP

**Agent Host Protocol 1.0 ja Copilot connectors** (julkaistu 28.10.) `[Seuraa]` - VS Coden Agent Host Protocol (AHP) on LSP:n ja DAP:n mallinen avoin, agenttiriippumaton protokolla hostin ja asiakkaiden välillä, ja se on nyt versiossa 1.0. Kuka tahansa voi tehdä asiakkaan, joka liittyy samoihin live-sessioihin kuin VS Code. Copilot connectors (preview, kaikissa Copilot-tilauksissa) tuovat Slackin, Notionin ja Microsoft Learnin kontekstin agenttisessioihin ilman erikseen asennettavaa MCP-palvelinta. [VS Code: Agent Host](https://code.visualstudio.com/docs/agents/concepts/agent-host) · [VS Code Wrapped](https://code.visualstudio.com/blogs/2026/10/28/vscode-wrapped)
*Miksi tärkeä / mitä kokeilla:* Jos AHP:lle syntyy muita asiakkaita, se voi yhtenäistää agenttisessioiden käytön editorista riippumatta; lue protokolladokumentti ja seuraa, tuleeko tukea muihin työkaluihin.

**Google Connected Apps Platform (preview)** (julkaistu 28.10.) `[Seuraa]` - Kehittäjä rakentaa yhden integraation, joka toimii sekä Searchissa että Gemini-sovelluksessa. Integraatio tehdään pilvessä ajettavalla MCP-palvelimella tai Androidin AppFunctions-rajapinnoilla, ja sovellus rekisteröidään Google Connected Consolessa. [Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/connected-apps-one-place/)
*Miksi tärkeä / mitä kokeilla:* Valmis MCP-palvelin on nyt jakelukanava myös Googlen kuluttajapinnoille; tämä on tiedoksi, jos tuotteella on Gemini-käyttäjiä.

## Toimintatavat ja arkkitehtuuripatternit

**Pitkäkestoiset agentit: checkpointit ja idempotentit kirjoitukset** (julkaistu 28.10.) `[Kokeile]` - Foundryn hosted-agenttien long-running resilience on GA, ja se on tarkoitettu tunteja tai päiviä kestäviin tehtäviin. Foundry voi käynnistää keskeytyneen työn uudelleen alkuperäisellä syötteellä, mutta Microsoftin ohjeen mukaan kehittäjän on itse tallennettava checkpointit ja tehtävä ulkoisista kirjoituksista idempotentteja. Tämä on yleinen patterni mille tahansa uudelleenkäynnistyvälle agentille. [Microsoft Foundry Blog](https://devblogs.microsoft.com/foundry/microsoft-copilot-harness-in-foundry/)
*Miksi tärkeä / mitä kokeilla:* Lisää omiin agenttiajoihin (esim. Claude Agent SDK -taustatyöt) tilatiedosto vaihe kerrallaan ja idempotenssiavain ulkoisiin kutsuihin, kuten PR:n luontiin tai ADO-work itemin päivitykseen, ennen kuin otat automaattisen uudelleenyrityksen käyttöön.

## Tietoturvavahti

**CVE-2026-93328: Google Cloud MCP Toolbox for Databases, CVSS 9.3** (julkaistu 26.10., uutisoitu 27.10.) `[Kokeile]` - Path traversal ja puuttuva autorisointi (CWE-22, CWE-862) versioissa 1.2.0–1.4.0. Autentikoimaton hyökkääjä voi muotoilluilla tool-kutsuparametreilla viedä isäntäkoneen tiedostoja ulkoiseen GCS-bucketiin ja ylikirjoittaa paikallisia tiedostoja. Korjaus on versiossa 1.5.0 (googleapis/mcp-toolbox PR 3454), ja julkinen PoC on olemassa. Kohde jäi pois eilisestä raportista. [OpenCVE](https://app.opencve.io/cve/CVE-2026-93328) · [CVE Brief 27.10.](https://cvebrief.com/archive/2026/10/27/)
*Miksi tärkeä / mitä kokeilla:* Jos MCP Toolbox on käytössä yhdenkin kehittäjän koneella tai palvelimella, päivitä se versioon ≥ 1.5.0 ja tarkista, ettei palvelin kuuntele verkossa ilman autentikointia.

**CVE-2026-112346: OpenHands Software Agent SDK, autentikoimaton RCE** (julkaistu 26.10.) `[Kokeile]` - DockerWorkspace- ja Apptainer-launcherit sitovat sandboxin agent serverin kaikkiin verkkoliitäntöihin tyhjällä `session_api_keys`-listalla, jolloin autentikointi on oletuksena pois päältä. Porttiin pääsevä hyökkääjä voi ajaa komentoja rootina, lukea työtilaa ja salaisuuksia. Haavoittuvia ovat versiot ennen 1.52.0 (`openhands-sdk`, `openhands-workspace`), ja CVSS on lähteestä riippuen 9.3–9.8. [OpenCVE](https://app.opencve.io/cve/CVE-2026-112346) · [Corgea](https://corgea.com/research/cve-2026-112346-93328-115915-vllm-openhands-google-mcp-october-2026)
*Miksi tärkeä / mitä kokeilla:* Yleinen opetus agenttisandboxeille: tarkista, että omat sandbox-palvelimesi sitoutuvat `127.0.0.1`:een ja vaativat tokenin; OpenHandsin käyttäjät päivittävät versioon ≥ 1.52.0.

## Hinnoittelu, saatavuus ja sääntely

**GitHub Enterprise sisältää nyt Copilot-pääsyn; Copilot Standalone $10/kk** (julkaistu 28.10.) `[Seuraa]` - GitHub Enterprise Cloud -lisenssin haltijat saavat Copilotin ilman per-seat-maksua, ja muut yrityksen käyttäjät saavat saman pääsyn Copilot Standalonella hintaan $10/käyttäjä/kk. Kuukausittaisia AI-krediittejä ei sisälly, vaan käyttö laskutetaan ensimmäisestä pyynnöstä yritysbudjetista. Budjetin loputtua completion ja next edit suggestions toimivat edelleen, mutta Chat, code review ja cloud-agentti vaativat budjettia. Pääsy on nyt avoinna account teamin kautta, ja self-serve tulee vaiheittain. [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot/)
*Miksi tärkeä / mitä kokeilla:* Laske, tuleeko tiimin nykyinen Copilot Business -seat-malli halvemmaksi vai kalliimmaksi puhtaalla käyttöpohjaisella laskutuksella, ennen kuin self-serve-siirtymä koskee teitä.
