## Uudet mallit ja versiot

**Gemini Omni 1.1 Flash GA – 40 sekunnin AI-videot, 4K ja keyframe-kontrolli API:ssa (Google DeepMind, julk. 27.8.2026)**

Google DeepMind julkaisi `gemini-omni-1.1-flash` -mallin yleisesti saataville 27.8.2026. Malli on edeltäneen preview-version (`gemini-omni-flash-preview`) pysyvä korvaaja; preview-päätepisteestä poistutaan 30.9.2026. Kyseessä oli johtava tulos joka jäi aiemmista raporteista; nostetaan nyt ensimmäistä kertaa.

**Tärkeimmät uudet ominaisuudet GA-julkaisussa:**
- **Scene extension**: olemassa olevan klipin jatkaminen 10 s:n paloissa, kumulatiivinen maksimi **40 sekuntia** (edellinen max 10 s)
- **First-and-last-frame interpolation**: video generoidaan kahden kuvan välillä (`image_to_video`, 2 kuvaa)
- **Resolution control**: 360p, 720p (oletus), 1080p ja 4K — 1080p ja 4K ovat upscale-tulostuksia, ei natiivisti korkeata resoluutiota
- **Video references**: hahmojohdonmukaisuus viiteklipin avulla

**Hinnoittelu:** ~$0,03/s 360p, ~$0,10/s 720p, ~$0,15/s 1080p, ~$0,30/s 4K.

*Miksi tärkeä / mitä kokeilla:* Gemini Omni 1.1 Flash on nyt helpoin reitti tuotantolaatuiseen ohjelmalliseen videogenerointiin Gemini API:n kautta: scene extension mahdollistaa pidempiä videokaaria ilman erillistä post-prosessointiputkea. Testaa erityisesti keyframe-kontrolli – se on kilpailuetu muihin video-API:hin nähden. Muista: preview-endpoint vanhenee 30.9., migroi ennen sitä.

## Repot ja yhteisön tekniikat (mitä kokeilla)

**Archify (tt-a1i/archify) – AI-agenttitieto arkkitehtuurikaavioihin suoraan koodausagentista (julk. 2026, GitHub trending 28.8.–1.9.2026)**

Archify on Claude Code-, Cursor- ja vastaavien AI-koodausagenttien agenttitaito, joka generoi arkkitehtuuri-, workflow-, sekvenssi- ja dataflow-kaavioita suoraan agentin keskusteluikkunasta. Tulos on itsessään sisältyvä HTML-tiedosto, joka sisältää valo/pimeä-teeman, liikkuvat animaatiot ja vientivaihtoehdot (mukaan lukien 1200×630 jakokortti README:hen tai sosiaaliseen mediaan).

**Miksi nousi trendingiin:** Repo sai 4 239 tähteä 28.8. ja on kasvanut noin 3 900–4 000 tähteä päivässä – yhteensä yli **32 500 tähteä** 1.9. mennessä. Kasvuvauhti asettaa sen tähtihistorian perusteella yhteen nopeimmin kasvavista developer-työkaluista syyskuussa 2026.

**Käytännöllinen arvo:** Sen sijaan että selittää agentille mitä piirtää ja sitten kopioi tuloksen diagrammityökaluun, Archify tekee koko piirron agentin sisällä: tulos on välittömästi jaettava HTML – ei PlantUML-koodi jonka pitää erikseen renderoida. Erityisesti koodipohjaan liittyvät arkkitehtuurikuvaukset, joita on vaikea ylläpitää manuaalisesti, ovat lupaava käyttötapaus.

*Miksi tärkeä / mitä kokeilla:* Lisää Archify Claude Code -agenttiisi (`/add-skill`) tai Cursorin MCP-liitännäisiin. Hyödyllisin käyttötapaus: suuri legacy-koodipohja, jonka arkkitehtuuria ei ole dokumentoitu – anna agentin generoida komponenttikartta suoraan koodista. Tarkista [GitHub: tt-a1i/archify](https://github.com/tt-a1i/archify) lisenssiehdot ennen tuotantokäyttöä.

## Tietoturvavahti

**KRIITTINEN: Aurora-kiristysohjelmatoimija käytti Cursor Agent + claude-4.5-sonnet-thinking -mallia suoraan uhriverkkoihin – ensimmäinen dokumentoitu tapaus (Gambit Security, julk. 27.8.2026; laaja mediakattavuus 31.8.2026)**

Gambit Security julkaisi 27.8. tutkimusraportin, joka nousi laajaan mediakattavuuteen 31.8. Aurora-kiristysohjelmatoimijat käyttivät Cursor Agentin kautta `claude-4.5-sonnet-thinking` -mallia hands-on-hyökkäystyöhön **10:ssä uhriorganisaatiossa** huhtikuun 8. – toukokuun 26. välisenä aikana 2026.

**Dokumentoidut hyökkäystehtävät:**
- Ympäristön tiedustelu: isäntien skannaus, käyttäjäoikeuksien kartoitus (NetExec, Nmap)
- VPN-asiakkaan asennus ja sertifikaattihyökkäykset
- ESXi-hypervisorien etsintä (`esxi_finder.py`) ja VMware-tiedostojen salaus
- Raporttien mukaan Aurora-toimija syötti Cursor Agentille uhrin ympäristöstä saatua kontekstia (tunnisteet, olemassa oleva reitti), minkä jälkeen agentti suoritti komentorivitoiminnot

**Miksi tämä on uusi kategoria:** Aiemmin havaittu AI:n väärinkäyttö on kohdistunut phishing-tekstien tai haittakoodin generointiin (staattinen käyttö). Aurora-tapaus on **ensimmäinen julkisesti dokumentoitu esimerkki** jossa uhkatoimija käytti AI-koodausagenttia interaktiivisesti post-kompromissivaiheen elävissä uhriverkkoympäristöissä – agentin kyvyt tiedusteluautomaatioon ja komennon suoritukseen käytettiin suoraan rikollisessa operaatiossa.

*Miksi tärkeä / mitä kokeilla:* (1) Ota käyttöön lokitus AI-koodausagenttien aktiviteetista kehitystyökaluista – Cursor Agentin ja vastaavien komentoriviaktiivisuus tulee olla näkyvissä auditointilokeissa. (2) Varmista että agentteja käytetään vain sandbox-ympäristöissä tai tarkoin rajatuilla käyttöoikeuksilla. (3) Laajempi oppitunti: **AI-koodausagentit, jotka voivat ajaa komentorivikomentoja, ovat nyt kyberuhkien käyttämiä työkaluja** – arvioi agenttiesi oikeuksia sen mukaisesti.

**Claude Code +50 % -kampanjaraja päättyy 31.8. – pysyvä +25 % korvaa sen 14.9., mutta nykyisille käyttäjille nettovaikutus on −17 % (Anthropic, ilmoitettu 29.8.2026)**

Anthropic ilmoitti 29.8., että keväällä 2026 lisätty ja elokuussa jatkettu +50 % väliaikainen kasvatus Claude Code -viikoittaisiin käyttörajoihin päättyy 31.8. Uusi pysyvä taso on +25 % perustasosta. Koska +50 % kampanja on laskentapohja nykyisille käyttäjille, heille nettovaikutus 14.9. alkaen on **−17 % nykyisestä tasosta** – vaikka Anthropicin viestissä puhutaan "+25 %:n korotuksesta".

**Vaikutukset:**
- Pro, Max, Team ja istuinpohjaiset Enterprise-sopimukset: kaikki laskevat 14.9.
- Uudet käyttäjät (eivät ole kokeneet +50 %-promoota): näkevät +25 % korotuksen
- Enterprise API (usage-based): ei muutoksia

*Miksi tärkeä / mitä kokeilla:* Tarkista nykyinen käyttötasosi dashboard.anthropic.com:ssa. Jos ajat automaatisia Claude Code -ajoja (scheduled tasks, CI-integraatiot), varaudu siihen että viikorttainen budjetti pienenee n. 17 % syyskuun 14. jälkeen. Harkitse ajontoistoa tai kriittisten automaatioajojen aikataulutusta alkuviikkoon ennen rajariskin kasvua.

| Alue | Muutos |
|------|--------|
